Damson — Mobile view

A read-and-edit mobile companion to the desktop DAM. Browse the library, drill into asset metadata, and make edits on the go. No upload/download flows — those stay on desktop.

Design system: reusing all desktop tokens (warm-neutral dark theme, yellow accent, Inter + JetBrains Mono, licence-status colours, lic-pills, thumb procedurals).
  • Shell: top app bar (menu · title · view-toggle), search inline, horizontal filter strip, scrollable body, bottom tab bar.
  • Browse: 2-up grid by default, list view as alt. Same procedural thumbs, type badges, review dots, lic-pills as desktop.
  • Filter drawer: hamburger opens a left drawer combining nav rail + filter sidebar (browse links, licence, file type, tag chips).
  • Detail sheet: full-screen sheet replaces the desktop side panel. Tags, licence, team notes are inline-editable. Description, projects, collections, versions, source are collapsible sections.
  • No upload/download: queue is read-only browsing of in-flight imports; no "Re-extract" or "Download original" buttons surfaced on mobile.
